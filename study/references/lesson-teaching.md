# `/study-n` Unit teaching and `/study-e` targeted clarification

## Unit

Use the already approved Unit+LP map. Teach **one Unit per `/study-n`**. Use a concise 7-stage logic (flexible layout): WHY → INTUITION → MECHANISM → EXAMPLE → CONNECTION → REMEMBER → CHECKPOINT. Explain real English terminology with Chinese on first use. Add one visual that best matches the knowledge relationship, with clear arrow semantics. Use a hidden mini-question where it helps learner predict a mechanism; grade only from submitted responses.

Select and adapt accepted STORM question IDs from the planning inventory; do not rerun a full multi-perspective research task on each Unit. Source-derived statements must preserve conditions and anchors. A false inference should be distinguished from source claims.

## `/study-e <topic>`

Save current Unit pointer. Find the exact blocking concept/LP. Teach: current position → simplest useful intuition → accurate definition/mechanism → a small example → a real Agent example → an engineering example → reconnect to original Unit. Use **different** examples, not paraphrase repetition. Optionally ask one changed-condition question and record the response as evidence. Return without moving current Unit.

## Correction

If wrong, identify the smallest failed concept and show why the response fails under the question's conditions. If the question is ambiguous, correct the question before rating the learner. Provide a new concrete example checking the same principle; avoid reteaching an entire chapter by default.
