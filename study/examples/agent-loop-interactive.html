逐层理解

小问题 1：Tool Result 为什么需要进入下一次 Context？

下一轮模型只能利用它实际接收到的信息。工具结果需要由运行时追加到下一轮的 Context 中。

小问题 2：如果 Tool Result 没有追加到 Context，会发生什么？

下一轮模型可能不了解工具输出，从而重复调用或基于缺失信息行动。
