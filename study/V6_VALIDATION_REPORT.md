## Known architectural boundary

V6 contains a real Manager `decide → execute tool → observe → decide` loop and isolated worker calls, with Host authority outside the model. It is not six always-on autonomous processes. A configured compatible model is required for live decisions; the included tests use a model test double. No background daemon or remote scheduling is installed.
