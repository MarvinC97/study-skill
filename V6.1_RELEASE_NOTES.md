# Study V6.1 Agent Runtime

V6.1 integrates V6.0 Manager/Host with the existing V3.5 learner-management features. Original V3.5 `references`, `schemas`, learner management scripts and assets are preserved in this repository. The new runtime lives in `study/runtime/`; model API setup is documented in `study/runtime/README.md` and `study/references/v6-agent-runtime.md`.

## Included

- Manager-driven routing, independent reviewers, source-span and content contracts, partial rework, and G1–G6 gates.
- Learner profile binding, actual answer evidence and return-point recovery, preserving V3.5 data schema.
- Two Chapter 8 HTML acceptance pages, plus browser and runtime tests.
- Existing seven commands retained: `/study`, `/study-n`, `/study-e`, `/study-d`, `/study-q`, `/study-c`, `/study-m`.

## Verification status

Automated offline tests were previously reported as 28/28 passing on the V6.1 ZIP. This merge preserves the original V3.5 assets and schemas; its combined repository configuration still requires end-to-end validation in the target Windows environment. A real provider-backed full chapter generation has not been verified. Treat this as a release candidate.

## Security

Keep API keys and personal learner records outside the public repository. Do not commit `~/Study/learners/`, workspace state, or secrets.
